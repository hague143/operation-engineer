# Abyss Solutions role: portfolio coverage

This compares the supplied job description with the **single-file HTML edition**. It is an independent portfolio exercise, with synthetic examples and human-entered observations. It does not claim employment, company affiliation, professional certification, or proficiency in software that the candidate has not used.

## Try the newly added tools

1. Open an editable inspection as **Inspector**. Add **synthetic P&ID** or upload a drawing image with its evidence type selected.
2. Open the image. Choose **Feature**, a discipline and component, add an equipment tag, draw a rectangle, then save the observation and follow-up.
3. Use **Edit assessment** to supply criteria, rationale and limitations. Document references are metadata; do not treat the family selector as a code assessment.
4. Open **3D / point-cloud lab**. The synthetic pipe has a 2 m coordinate distance between vertices 0 and 160. Alternatively import a small supported geometry file and declare its actual coordinate units. Save a labelled measurement to a draft inspection.
5. Complete and **Save inspector QA**, then submit. Switch to **Reviewer**, complete and **Save reviewer QA**, then approve, or request changes with a comment.
6. Open **Analysis & worklist** for filters, counts, CSV or the Excel XML workbook. Open the inspection report to **Print / Save PDF**.
7. **Download shareable HTML** preserves saved geometry, measurements, assessment, QA, photos and annotations in a new independent copy. Older version 1 JSON backups remain compatible; missing QA stays unrecorded rather than being invented.

## Geometry constraints

Imports are local text files up to 8 MB, 20,000 vertices and 20,000 triangles. XYZ/CSV expects x, y, z as the first three columns, with an optional `x,y,z` header. ASCII PLY supports scalar vertex properties containing x/y/z and optional faces with a vertex-index list. OBJ imports vertices and triangulated faces, including relative indices. OBJ vertices use xyz with optional weight 1 (vertex colours and other weights are not imported); materials, textures and external resources are not loaded. Unknown units permit viewing but disable saving measurements. Saved measurements retain copied endpoints when the active model is replaced.
